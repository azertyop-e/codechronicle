Introduction

GitHub est la plateforme de référence pour héberger des dépôts Git et collaborer sur des projets logiciels.

Qu'est-ce que Git ?

Git est un système de contrôle de version distribué. Chaque développeur possède une copie complète de l'historique du projet.

Créer un dépôt

git init
git remote add origin https://github.com/utilisateur/mon-projet.git
git push -u origin main

Pull Requests

Les PR permettent de proposer des modifications, de les faire relire et de les fusionner proprement sur la branche principale.

Conclusion

Maîtriser GitHub est essentiel pour tout projet DevOps moderne.
